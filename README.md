# Multi-Level Framework for Scientific Writing — Companion and Prompt Library

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.PLACEHOLDER.svg)](https://doi.org/10.5281/zenodo.PLACEHOLDER)

A companion to Andreas Trabesinger's [*Multi-level framework for scientific writing*](https://doi.org/10.5281/zenodo.18148137), published on Zenodo. That document sets out four hierarchical levels of scientific writing — manuscript, section, paragraph/sentence, word — as a single-page visual reference. This repository expands each level into full checklists **and** converts every checklist item into a ready-to-use prompt for AI-assisted writing and editing.

## What's in this repository

- **[`framework-companion.md`](framework-companion.md)** — the full companion document: expanded checklists for all four levels, plus an appendix of AI prompts organized by level.

## How to use it

- **As a reference**: read the checklists directly, top to bottom for writing, bottom to top for editing.
- **With an AI assistant**: copy a prompt from the appendix, paste your draft, and ask. The prompts are written generically and work with any LLM-based assistant.

This document gives you the diagnostic categories. Applying them to your own manuscript — with feedback on the judgment calls where they overlap or conflict — is what the [scientific writing workshops](https://reinschrift.ch) are for.

## Versioning

This companion tracks the version of the framework it accompanies. The current release corresponds to Framework v1.4. Substantive updates will be tagged as new releases and archived to Zenodo with their own DOI (see below), while the concept DOI stays constant across versions.
